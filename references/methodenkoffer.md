# Methodenkoffer

Werkzeuge je Modul. **Pragmatisch einsetzen, nicht dogmatisch** — nur so viel
Methode, wie das Problem trägt. Für die meisten kleinen Vorgänge genügt je Modul
ein einziges Werkzeug. Die Auswahlspalte „nimm, wenn" ist wichtiger als die Liste.

---

## SA — Situationsanalyse

| Werkzeug | Nimm, wenn | Kern |
|----------|------------|------|
| **Desk Research** | Wissen existiert, ist nur verstreut | Wissensbasis, Dokumente, Repos, Daten zusammentragen — vor jeder Rückfrage |
| **Gezielte Rückfrage** | Nur der Nutzer kann es wissen | Wenige, präzise Fragen; nie Fragen, deren Antwort auffindbar ist |
| **Systemskizze** | Technisches oder verkettetes Problem | Grenze, Elemente, Flüsse, Schnittstellen |
| **Stakeholder-Übersicht** | Menschen sind beteiligt oder betroffen | Wer verursacht / leidet / entscheidet / muss mitziehen |
| **Gap-Analyse** | Es gibt eine klare Erwartung | Ist gegen Erwartung, Abstand benennen |
| **SWOT** | Strategische Lage, kein akuter Fehler | Stärken/Schwächen (innen), Chancen/Risiken (außen) |

## PE — Problemeingrenzung

| Werkzeug | Nimm, wenn | Kern |
|----------|------------|------|
| **Ist / Nicht-Ist** | Immer. Das Grundwerkzeug des Moduls | Was/Wo/Wann/Bei wem/Wie stark — jeweils auch die Negativabgrenzung |
| **5-Why** | Ursachenkette vermutet linear | Fünfmal „warum", jede Stufe belegen |
| **Ishikawa** | Mehrere Ursachenfelder plausibel | Mensch, Maschine, Methode, Material, Mitwelt, Messung |
| **Issue Tree** | Problem zerfällt in Teilprobleme | Überschneidungsfrei und vollständig zerlegen |
| **Anforderungsliste** | Zielzustand hat mehrere Dimensionen | Forderungen (Pflicht) von Wünschen (Kür) trennen |

## AL — Alternative Lösungssuche

| Werkzeug | Nimm, wenn | Kern |
|----------|------------|------|
| **Abstraktion des Ziels** | Immer, als Vorstufe | Zielzustand eine Stufe abstrakter fassen, damit keine Lösungsrichtung vorweggenommen wird |
| **Analogie / Präzedenz** | Ideengeber A | Wer hat ein strukturgleiches Problem gelöst — andere Branche, Natur, eigene Vorgeschichte |
| **Systematische Variation (SIT)** | Ideengeber B | Streichen, Vervielfachen, Umkehren, Aufteilen, Zusammenlegen, Verlagern, Zeitpunkt verschieben |
| **6-3-5 (adaptiert)** | Zwei Ideengeber reichen nicht | Mehrere Runden, jede baut auf der Vorrunde auf |
| **Morphologischer Kasten** | Lösung setzt sich aus Teilfunktionen zusammen | Teilfunktionen × Ausprägungen, Kombinationen bilden |
| **Null-Variante** | Immer, Pflicht | Was passiert, wenn nichts getan wird |

## LA — Lösungsauswahl

| Werkzeug | Nimm, wenn | Kern |
|----------|------------|------|
| **Ausschlusskriterien** | Immer zuerst | K.-o.-Bedingungen vor jeder Punktvergabe prüfen |
| **Nutzwertanalyse** | ≥3 Alternativen, Kriterien messbar | Gewichte (Σ 100 %) × Bewertung 0–10 |
| **Paarweiser Vergleich** | Wenige Alternativen oder unklare Skalen | Jede gegen jede, Siege zählen |
| **RICE** | Vorhaben mit Reichweite und Aufwand | Reach × Impact × Confidence / Effort |
| **Sensitivitätsprobe** | Immer nach der Rechnung | Kippt die Reihenfolge bei kleiner Gewichtsänderung? |

## TA — Tragweitenanalyse

| Werkzeug | Nimm, wenn | Kern |
|----------|------------|------|
| **Prä-Mortem** | Immer bei kleinen Vorgängen — bestes Aufwand/Ertrag-Verhältnis | „Die Umsetzung ist gescheitert. Warum?" |
| **Szenariotechnik** | Zukunft offen, mehrere Entwicklungen denkbar | Bestes / erwartetes / schlechtestes Szenario |
| **FMEA-artige Betrachtung** | Technische Lösung mit Fehlermodi | Fehler, Ursache, Folge, Entdeckung, Maßnahme |
| **Risikomatrix** | Viele Risiken zu sortieren | Eintritt × Wirkung, grob (hoch/mittel/gering) |
| **MVP-Zuschnitt** | Risiko liegt in der Größe des Schritts | Kleinste Umsetzung, die das Prüfkriterium testet |

## EU — Entscheiden und Umsetzen

| Werkzeug | Nimm, wenn | Kern |
|----------|------------|------|
| **FOR-DEC** | Immer für die Entscheidung | Facts, Options, Risks & Benefits, Decision, Execution, Check |
| **Phasenplan** | Immer für die Umsetzung | Planen / Durchführen / Abschließen |
| **Kommunikationsplan** | Andere Menschen sind betroffen | Wer erfährt was, wann, von wem |
| **Abbruchpunkte** | Umsetzung mehrstufig oder riskant | Vorab festlegen, woran erkannt wird, dass gestoppt werden muss |

## NL — Nacharbeiten und Lernen

| Werkzeug | Nimm, wenn | Kern |
|----------|------------|------|
| **Zielabgleich** | Immer | Prüfkriterium aus PE anwenden, unverändert |
| **Lessons Learned** | Immer | Was lief gut, was nicht, was ist übertragbar |
| **Retrospektive auf den Methodeneinsatz** | Vorgang war aufwendig | Welches Modul war überflüssig, welches zu knapp |
| **Abnahmeprotokoll** | Ergebnis wird an jemanden übergeben | Was wurde geliefert, was ausdrücklich nicht |
